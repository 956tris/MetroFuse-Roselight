Roselight 1.0.10 polishes the Apple Music UI on Android and Desktop with a liquid-glass floating mini-player and tab bar, refined Apple Music crimson accents, and Apple-styled Settings and Plugins management screens powered by `ui.settings` and `ui.plugins`.

Update MetroFuse to [10.0 Beta 7](https://github.com/956tris/MetroFuse/releases/tag/v10.0.0-kmp-beta.7) for custom Settings and Plugins screens support. Import the APK on Android or the JAR on desktop through MetroFuse Settings > Plugins > Import or update plugin (or via the Marketplace). Enable Roselight and choose it under App interface.

Back up your library, playlists and settings before migration, and use the original interface while updating the host and plugins. Beta instability, crashes, plugin incompatibility, incomplete features and migration data loss are possible. Provider account, library, radio, lyrics and playback features depend on the host and selected provider. Use the host restore icon to return to the original interface if a screen misbehaves.
