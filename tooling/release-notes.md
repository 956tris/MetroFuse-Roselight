Roselight 1.0.9 adds provider-backed Library for Spotify and YouTube Music, word-timed lyrics, and an album-cover fallback for Now Playing. The player uses the measured playback duration when MetroFuse provides it. Build metadata records the source and host SDK commits.

Update MetroFuse to [10.0 Beta](https://github.com/956tris/MetroFuse/releases/tag/v10.0.0-kmp-beta.1) for the Library and playback fixes. Import the APK on Android or the JAR on desktop through MetroFuse Settings > Plugins > Import or update plugin. Enable Roselight and choose it under App interface.

Back up your library, playlists and settings before migration, and use the original interface while updating the host and plugins. Beta instability, crashes, plugin incompatibility, incomplete features and migration data loss are possible. Provider account, library, radio, lyrics and playback features depend on the host and selected provider. Use the host restore icon to return to the original interface if a screen misbehaves.
